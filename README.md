## About Wake Intelligence

The **Wake Intelligence MCP Server** provides temporal intelligence for AI agents through a 3-layer brain architecture:

```
┌─────────────────────────────────────────────────────────┐
│                 WAKE INTELLIGENCE                        │
│            3-Layer Temporal Brain Architecture           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   Layer 1: CAUSALITY ENGINE (The Past)                  │
│   ─────────────────────────────────────────             │
│   Tracks WHY code was created and its relationships     │
│                                                         │
│   Layer 2: MEMORY MANAGER (The Present)                 │
│   ─────────────────────────────────────                 │
│   Manages relevance with tiered memory system           │
│   (Active → Recent → Archived)                          │
│                                                         │
│   Layer 3: PROPAGATION ENGINE (The Future)              │
│   ─────────────────────────────────────                 │
│   Predicts what context will be needed next             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Why the Rename?

The original name `semantic-context-mcp` was generic. The new name `semantic-wake-intelligence-mcp` better describes the unique innovation:

- **Wake** = The system "wakes up" with temporal awareness
- **Intelligence** = Not just retrieval, but prediction and causality
- **MCP** = Model Context Protocol server
